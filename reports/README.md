# Reports

Chaque notebook doit écrire ses livrables dans un sous-dossier portant le même nom :

- `reports/00_notebook/`
- `reports/01_notebook/`
- `reports/notebook_2/`
- `reports/notebook_3a/`
- `reports/01_notebook3_b/`
- etc

Cela facilite la collaboration et la traçabilité des résultats.
